## Recommended plain-text description

Only the text inside this block is the description field; the review annotations below it are not listing copy.

```text
Put your team's AI spending and delivery patterns in context.

Tokens Dashboard helps team leads, engineering managers, and project leads explore model spending, token usage, and delivery outcomes with local sample data.

Start with the summary, then open Cost by Model, Tokens versus Outcomes, or Ticket to Merge to examine the detail.

AI Usage Insights presents team-level review cards with a supporting metric, an explanation, a suggested next step, and a caveat. The insights use deterministic local rules, without calling an LLM at runtime.

Use the signals to identify questions worth reviewing before changing team guidance. The app does not establish that AI usage caused a delivery result, and it does not provide individual employee scores or performance rankings.

This course version uses local sample data and does not connect to your team's live production systems. Version 1.0 uses fixed insight thresholds and does not link insight cards directly to supporting charts.

Requires an iPhone running iOS 27.0 or later.
```
